# User Stories — сервис онлайн-записи в салон красоты

## Клиент

| ID | User Story | Приоритет |
|---|---|---|
| US-01 | Как клиент, я хочу просматривать список услуг с описанием, стоимостью и длительностью, чтобы выбрать подходящую услугу. | Must |
| US-02 | Как клиент, я хочу просматривать список мастеров и информацию о них, чтобы выбрать специалиста. | Must |
| US-03 | Как клиент, я хочу выбрать услугу, мастера и дату, чтобы увидеть доступное время для записи. | Must |
| US-04 | Как клиент, я хочу видеть только свободные временные интервалы с учётом длительности услуги, чтобы выбрать подходящее время. | Must |
| US-05 | Как клиент, я хочу создать запись на выбранную услугу к выбранному мастеру, чтобы забронировать время посещения салона. | Must |
| US-06 | Как клиент, я хочу просматривать список своих записей с информацией об услуге, мастере, дате, цене и времени, чтобы контролировать предстоящие посещения. | Must |
| US-07 | Как клиент, я хочу отменить свою запланированную запись до начала посещения, чтобы освободить время мастера, если не смогу прийти. | Must |

## Мастер

| ID | User Story | Приоритет |
|---|---|---|
| US-08 | Как мастер, я хочу просматривать своё расписание с информацией о записях, цене, клиентах, услугах и времени посещения, чтобы планировать рабочий день. | Must |

## Администратор

| ID | User Story | Приоритет |
|---|---|---|
| US-09 | Как администратор, я хочу добавлять новые услуги с указанием названия, описания, стоимости и длительности, чтобы поддерживать актуальный перечень услуг салона. | Must |
| US-10 | Как администратор, я хочу изменять информацию об услугах, чтобы актуализировать данные о стоимости и длительности процедур. | Must |
| US-11 | Как администратор, я хочу деактивировать услуги, которые больше не предоставляются, чтобы убрать их из каталога и сохранить историю записей. | Must |
| US-12 | Как администратор, я хочу просматривать все записи клиентов, чтобы контролировать загруженность салона. | Must |
| US-13 | Как администратор, я хочу отменять запланированные записи клиентов, чтобы управлять расписанием в случае необходимости. | Must |
| US-14 | Как администратор, я хочу просматривать список мастеров, чтобы управлять информацией о специалистах салона. | Must |
| US-15 | Как администратор, я хочу создавать, редактировать и деактивировать профили мастеров, чтобы поддерживать актуальный список специалистов салона. | Should |

В рамках редактирования профиля только администратор может загрузить, заменить или удалить фотографию мастера.

## Любой пользователь

| ID | User Story | Приоритет |
|---|---|---|
| US-16 | Как пользователь, я хочу зарегистрироваться в системе, чтобы получить доступ к личному кабинету и возможности записи. | Must |
| US-17 | Как зарегистрированный пользователь, я хочу авторизоваться в системе, чтобы получить доступ к функциям в соответствии со своей ролью. | Must |
| US-18 | Как незарегистрированный пользователь, я хочу просматривать информацию о салоне, мастерах и услугах, чтобы ознакомиться с предложениями салона перед регистрацией. | Should |
